# Amazon 图片需求生成器 V2.4

这是一个面向亚马逊运营、美工和多语审核人员的本地 Python 桌面程序。它把产品资料、尺寸变体、竞品、关键词、品牌规范和模块规划，转换为可执行的 Excel 图片需求表、六语文案、JPG 参考图和德语主文案效果图。

默认示例产品为旅行行李箱，但开放式属性和可增删变体适用于其他品类。AI 图片是构图与氛围参考，不替代真实产品摄影、人工排版或上架前合规审核。

## V2.4 更新重点

- 产品变体增加“复制选中”：复制尺寸、颜色、重量、容量与价格，并为名称和 SKU 添加副本标识，便于快速制作相邻尺寸/颜色变体。
- 选中变体后可直接编辑；按 Enter、离开输入框、切换变体或保存/导出项目时自动保存，不再需要点击“更新选中”。
- 图片供应商新增 `CUN.AI 图片生成`，共用 `CUNAI_API_KEY`，从 `GET /v1/models` 读取账户实际模型，并按 OpenAI Compatible `/images/generations` 路径调用。
- “图片合规AI检查”紧跟“文案溢出检查”显示，减少宽屏右侧操作距离。
- 局部图片重生强制绕过结果缓存，确保重生会请求新结果；普通重复请求仍可使用缓存节约时间和费用。

## V2.3 更新重点

- 新增 `CUN.AI` 文案供应商：`https://www.cun.ai/v1`、`/chat/completions`、`/models`、环境变量 `CUNAI_API_KEY`，默认模型 `claude-fable-5`。
- 所有供应商连接参数迁移到 `amazon_image_brief/resources/ai_providers.json`；后续修改 URL、协议、Endpoint、Key 环境变量、默认模型或请求头只需编辑该文件并重启程序。
- AI 设置页移除协议、Base URL、Endpoint、Key 名称、临时 Key 和请求头输入，仅保留供应商/模型下拉、获取全部模型和测试连接。
- “获取全部模型”调用供应商模型接口；文案“测试连接”还会发送一条极短对话，验证所选模型的 Chat Completions/Responses 调用链。
- 新增 `cun_ai_test.py`，可脱离 GUI 运行 CUN.AI 模型列表与短对话连通测试。

## V2.2 基础能力

- 模块页采用“左侧可添加 / 右侧已选择”双栏布局，已选模块即时可见；确认页支持 Ctrl/Shift 多选与批量删除。
- AI 页增加真实连通测试、供应商模型列表自动获取、主/备用供应商自动切换、失败重试、每分钟请求限流和生成前费用估算。
- 本机内容寻址缓存会复用相同文案及图片请求；API Key 不进入缓存键或缓存元数据。
- 新增持久化异步 SKU 队列，支持批量导入项目 JSON、暂停、继续、失败重试和意外退出后的续跑。
- 新增画笔蒙版选区式局部重生、产品结构锁定提示及生成图与产品参考图的相似度检测。
- 新增 OCR/图片文字风险检查、六语回译、文案溢出检测和图片本地合规检查；会产生模型调用的检查默认关闭，由用户主动开启。
- 内置按站点和品类匹配的 Amazon JSON 规则库，支持导入本地新版或从 HTTPS 地址更新；每次完整导出前自动预检。
- Excel 扩展为 28 列，并增加 `Amazon规则预检` 工作表；输出目录同时保存 `preflight_report.json` 与 `qa_report.json`。

## V2.1 基础能力

- 文案与图片使用两套独立供应商配置，可分别选择 OpenAI、国内 AI 或自定义兼容 API。
- 预置文案供应商：OpenAI、CUN.AI、阿里云百炼、火山方舟、智谱、SiliconFlow、百度千帆和自定义 API。
- 预置图片供应商：OpenAI GPT Image、CUN.AI、阿里云通义万相、火山 Seedream、智谱 CogView、SiliconFlow 和自定义 API。
- API Key 仅从项目 `.env` 或本机环境变量读取，不写入供应商 JSON、项目 JSON、Excel 或源代码。
- 模型、协议适配器、Base URL、Endpoint、Key 环境变量名和附加请求头均由供应商 JSON 维护。
- 模块选择改为“模块实例”：同一种主图、A+、Brand Story 或旗舰店模块可重复添加，每个实例都有独立 ID、顺序、Prompt、六语文案、版本、审核和局部图片重生状态。
- 旧 V2 项目 JSON 会自动迁移；重复模块会生成唯一实例 ID，不覆盖彼此的数据。

## 关于 ChatGPT/Codex 直连

ChatGPT/Codex 登录用于 Codex 客户端自身的订阅访问，不是可由任意本地 Python 程序复用的通用 API 凭据。官方支持的程序化 OpenAI 调用仍应使用 Platform API Key；本项目不会读取 Codex 登录令牌或浏览器会话。因此，V2.4 采用“供应商 API + 文件化兼容接口”的方式生成文案和图片。

详见 [AI供应商配置指南.md](AI供应商配置指南.md)。

## 既有能力

- 目标站点下拉覆盖 23 个 Amazon 商城入口。
- 变体可新增、复制、自动保存编辑和删除；每个变体独立录入名称、SKU、尺寸、颜色、重量、容量和价格。
- 品牌语气、视觉风格、字体建议和品牌色提供可编辑预设；Logo 可在本地提取主色。
- 竞品与关键词支持手动录入或 Excel 导入，并提供 `竞品关键词导入模板.xlsx`。
- 主图默认 9 张，高级 A+ 默认 7 个模块，同时支持 Brand Story 和品牌旗舰店。
- 确认页支持拖拽/按钮排序、复制实例、删除实例和逐实例 Prompt。
- 六语文案覆盖英语、中文、德语、法语、意大利语和西班牙语；支持局部/全局重生成、版本对比、审核状态和 AI 自查。
- Excel 每行包含实例 ID、序号、PC/移动尺寸、三类图片、设计说明、Prompt、六语文案、版本、审核、自查和合规字段。

## 安装与启动

建议使用 Python 3.11 或更高版本。

```powershell
cd "E:\欧洲亚马逊资料\Codex项目\Amazon-Seller-Automation-Tools\images"
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

安装完成后也可双击 `run_app.bat`。代码更新不会删除项目目录内已有的 `.venv`、`.env` 或 `outputs`。

## AI 配置

1. 把 `.env.example` 复制为 `.env`，填写实际使用的 Key；例如 CUN.AI 使用 `CUNAI_API_KEY=你的真实Key`。
2. 打开程序的“AI 接入”页，分别从下拉框选择文案供应商和图片供应商。
3. 点击“获取全部模型”，再从模型下拉框选择当前账户可用模型。
4. 点击“测试连接”验证模型列表和调用接口；文案测试会产生极少量 token。
5. 按需设置备用供应商、重试、限流、缓存和费用预估；再启用 AI 文案、AI 图片及质量检查。

CUN.AI 图片预设不硬编码模型名，因为图片能力取决于账户实际可见模型。选择 CUN.AI 后请先点“获取全部模型”，再选择明确支持图片生成的模型；若网关未开放 `/images/generations` 或模型仅支持文本，程序会显示真实接口错误并按配置尝试备用供应商。

需要修改供应商参数时编辑 `amazon_image_brief/resources/ai_providers.json` 并重启程序。快速测试 CUN.AI：

```powershell
python cun_ai_test.py
```

没有 API Key 时，程序仍可生成本地六语基础文案、设计说明和完整 Excel；AI 改写、自查、生图及局部重生需要所选供应商的有效 Key。模型权限、区域、价格和限流以供应商控制台为准。

## 推荐工作流

1. 在“产品与变体”页填写已验证资料，选择站点并上传真实产品白底图。
2. 设置品牌预设；需要时上传 Logo 并提取品牌色。
3. 在“竞品与关键词”页手动录入，或导出模板后填写并导入。
4. 从左侧模块目录多次添加所需模块，在右侧即时核对；到确认页复制、批量删除、排序并填写每个实例的 Prompt。
5. 在“六语文案审核”页生成初稿，执行局部或全局重写、版本对比、状态标记和自查。
6. 在“AI 接入”页测试连接并估算费用；批量 SKU 可加入持久化队列，单项目在“生成与导出”页执行。
7. 在“批量任务与合规”页先运行规则预检；需要时用蒙版局部重生并复核结构相似度、OCR、回译和溢出结果。
8. 美工依据 Excel 的尺寸、设计说明、六语文案和 JPG 参考图制作终稿，并在上传前核对 Seller Central 实时规则。

## 质量控制选项说明

- `产品结构锁定`：在图片 Prompt 中要求保持真实参考图的箱体轮廓、轮组、拉杆、缝线、Logo 位置、材质和颜色。它是生成约束，不是像素级锁定，也不能代替人工复核。
- `最低相似度(0–100)`：生成后用本地图像特征比较 AI 图与产品参考图；低于阈值时写入警告，但不会自动判定合规或删除图片。场景图背景变化大，通常应比白底图/细节图使用更低阈值。
- `启用结果缓存`：相同供应商、协议、地址、模型、Prompt、画幅、质量、参考图和蒙版再次请求时，直接复用 `.cache/ai` 中结果，节约时间和 API 费用。API Key 不进入缓存键；局部重生会主动绕过缓存。

## 合规与数据边界

- 白底首图必须是主图第 1 张，纯白背景，只展示售卖产品，不添加文案、图标、道具或促销信息。
- 关键词只可自然用于可见文案和对应画面语义，不使用隐藏文字或无关词堆砌。
- 不自动编造尺寸、容量、测试、认证、排名、评分、奖项、保修或竞品比较结论。
- AI 参考图必须对照真实产品图复核外形、颜色、材质、零件和附件。
- 各供应商对参考图、尺寸和异步任务的支持不同；不兼容时会给出错误或生成占位图并记录警告。
- 程序中的尺寸是策划建议；最终以上传时 Seller Central 创建器提示为准。
