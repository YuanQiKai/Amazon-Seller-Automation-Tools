# V2.11：暂停续跑、贴图精排与连贯A+海报

## 1. 中断处理和继续生成

“5 六语文案审核”和“8 生成与导出”分别有“中断处理（暂停）”和“继续生成”。两组控制独立，文案暂停不会暂停图片阶段，反之亦然。

点击暂停后先显示“暂停请求已接收”，当前已经发送的请求会继续等待响应，返回后保存当前模块的结果。到下一个安全断点显示“已暂停”，不会再开始后续模块、校验重试或备用供应商请求。点击继续后接着原任务运行，已经完成的模块不重新请求。HTTP请求本身不强制断开，也无法取消供应商已经开始的生成或计费。

暂停时窗口仍可查看已完成的文案、图片及接口JSON。版式规划在本轮运行期间锁定，避免后台生成使用旧坐标而前台显示新坐标；文案/图片审核继续沿用已有增量保存机制。

这是同一次程序运行中的断点继续。退出程序会保存已收到的结果；重启后加载配置，再手动选择未完成模块重生，不自动发起付费请求。批量SKU队列仍使用原有队列暂停/续跑按钮。

## 2. 文案贴合图片的排版

先点击“预览卖点与版式”，为每个模块检查主卖点和实物依据。新增六类预设：

- 主视觉：上方居中标题、较小副标题，产品两侧用短说明和引线指向对应部位。
- 细节证据：完整产品或特写配部件标注，避免虚构结构。
- 场景叙事：杂志式标题和浮动说明，保留主要场景。
- 参数对照：顶部标题、产品规格展示、底部参数卡。
- 多卖点：清晰主次标题与分开的卖点卡片。
- 使用答疑：问题、答案、步骤与配套产品图。

“精调文本位置 / 字号 / 部位引线”打开编辑器。选择PC或mobile，选择一行文案对应的文本框，拖动位置，或输入X/Y/宽/高百分比。字号是画布短边的百分比，可选left/center/right对齐，功能引线可输入产品部位锚点。应用后保存至当前模块与配置。部位坐标是构图规划，不是自动识别的真实产品部件，需对照实物调整。

文案模型会看到完整布局、每行用途、卖点依据及其他模块已用标题；图片模型遵循同一规划生成无字素材，本地再排入德语文案。字体按品牌建议选用可用衬线或无衬线字体，缺少对应字体时回退到系统Arial/Georgia等，不保证安装了所有推荐字体。

六语、PC与移动端逐文本框检查溢出。过长文案不会被裁掉，会保留AI原图并提示具体文本框。请缩短对应文案或扩大该框后重排。首张白底主图始终不加文字；已手动确认的旧左右版式为兼容性保留，可主动换为新预设。

## 3. 一体式连贯A+海报

在文案页或导出页勾选“将全部A+章节作为一体式连贯海报制作”。选择品牌浅色、深色奢雅、纯白极简或冷灰科技主题，填写全组风格/修改要求，点击“应用整体规划”。品牌色及字体来自“产品与变体”的品牌规范。

全部高级A+实例按选择顺序组成故事板，每章有主卖点、前后章节衔接和同一全组要求。统一底色、品牌色贯穿线、字体及网格完成连续阅读效果，PC与移动端分别排版。它不是把照片背景变为一张跨章节像素无缝的超长摄影图；当前供应商适配优先传入首张真实产品参考图，连贯性由共享策划、风格Prompt和本地统一版式实现。

主图、Brand Story和旗舰店完全不加入A+海报。重复A+模块保留各自实例与顺序。

先生成文案、再生成图片。导出页的“A+连贯海报”页签可以滚动预览PC或移动端整幅；一章图片完成就更新一次，未完成或排版失败章节会显示明确提示。

整体修改有三种操作：

1. 按整体要求重生A+文案：仅重生A+六语，不改其他渠道文案。随后审核并按需更新图片。
2. 按整体要求重生A+图片：确认后仅请求全部A+章节图片，可能产生供应商费用，旧图历史保留；支持图片暂停和继续。
3. 只更新排版与导出：基于已有图片和当前文案重新制作PC/移动端海报、Excel和ZIP，不调用AI。用于改文字、主题、品牌色、字体、文本框位置及章节顺序；仅输入“改成机场场景”等自然语言不会改变原图，场景变化应使用第二项。

仍可用原有单图/蒙版重生修改某一章，完成后自动更新该章与全组总览。取消连贯模式后的新导出不再包含海报，历史文件不会删除。

## 4. 文件交付与上架边界

导出文件包含：

- 原需求Excel：高级A+的德语效果图列使用新排版结果，设计说明包含每行文本位置和章节关系；新增“A+连贯海报”工作表，含PC/移动端整幅预览、各章文件链接、尺寸和状态。
- `aplus_poster/<版本指纹>/`：PC整幅JPG、移动端整幅JPG、各章PC/移动端JPG、manifest清单；修改产生新版本，旧文件保留。
- 图片ZIP：AI无字原图、德语效果图、完整海报与章图，按文件夹分类。

章节画布是PC 1464×600、移动1200×900的统一设计参考。整幅长图**不能当作一张A+图片直接上传**。视频模块只交付封面/视觉参考，轮播只交付章节关键帧；双图/四图需要按字段拆图，热点、问答、比较表、文本须在Seller Central配置。原Excel中的各模块建议尺寸仍保留供设计拆分，正式规格以目标站点后台为准。章节很多时只缩小整幅总览，独立章节仍保持尺寸。

Amazon建议结合模块文本字段、适量图片文案和移动端可读性，而不是将全部长文埋入图片。可参考[官方A+设计指南](https://sell.amazon.com/blog/a-plus-content-design-guide)和[官方A+功能说明](https://sell.amazon.com/tools/a-content)。本程序不保证关键词索引、转化率或自动审核通过，必须人工检查产品真实性、引线部位、翻译和上架合规。

## 5. 升级与配置

版本为2.11.0，继续使用原有Python启动方式，无需重新输入供应商Key。退出旧窗口再启动`run_app.bat`即可加载新代码。`user_data`、`.env`、供应商配置、队列和旧输出不会因代码更新被清空；海报选项、主题、整体要求、精排坐标和生成海报副本进入原有保存配置机制。

自动测试均使用本地模拟接口，不代表真实供应商已验证出图质量或连通性；请先用少量模块试生成并审核，再批量运行。
