# V3.0.2 使用说明

## 推荐操作顺序

1. 关闭旧程序，用 `run_app.bat` 重启。无需重新输入已保存的配置；配置下拉和自动恢复沿用 `user_data`。不要在更新时清空这个目录或覆盖 `.env`、`ai_providers.json`。
2. 在产品与变体录入真实参数、卖点、禁用声明，并上传全部产品实拍。价格等信息会作为产品事实传入，但不代表允许把价格画进 Amazon 图片。
3. 在 AI 接入页选文案和图片供应商、模型。产品理解、参考图解析需要**支持图片输入的文案模型**；模型列表出现某名称不代表它支持视觉。普通纯文本模型无法替代真实看图。
4. 在模块选择页添加模块；高级导航轮播新增时默认 4 帧。帧数输入同时用于新轮播；选中已有组任意一帧后，可点击“应用到所选轮播组”。每帧在列表中分别显示，支持原有排序、删除、审核。复制某帧是在该组内增加一帧。
5. 在“六语文案审核 → 产品上下文（先喂给AI）”可先查看/补充分析要求，点击“分析 / 继续上下文”。也可直接开始生成，程序会先自动分析。界面显示每批请求 Prompt、图片清单和 AI 回复；请求头、URL、参数、响应、错误查看“接口请求与返回 JSON”。
6. 在“逐图文案 Prompt”选择目标帧，填写要求，或点击 AI 优化当前/全部；优化成功一帧就写回该帧原字段，并保留前后提示词历史。
7. 在卖点版式页先预览规划，再使用 AI 自动排版当前/全部模块。AI 根据产品事实、该帧卖点、提示词、已有文案和风格分析分别安排 PC/移动端文本框与产品区域。可继续拖动精调；白底首图始终不排文字。
8. 生成六语文案并审核。默认左侧可编辑德语，右侧显示中文；两侧语言可分别切换。“历史版本对比”仍在右侧子页签。每个完成模块即时更新。
9. 在“生成与导出 → 逐图生图 Prompt / 风格参考”选择一帧，设置图片 Prompt，追加上传该帧布局/风格参考图。现在直接生成含确认德语文案的最终图，不生成无字底图或额外叠字副本。可一键跟随当前预览模块，也可批量优化全部图片 Prompt。
10. 开始生成导出。也可在已有文案/图片结果基础上“生成/重生本帧”、填写修改意见或使用蒙版重生。运行中的暂停/继续沿用 V2.11 机制：当前已发送请求会返回并保存，之后停止发送新请求。

## 上下文到底怎么传入

- 不是“先聊天一次，供应商就永久记住产品”。接口通常无会话记忆；程序对产品事实、图片内容和模型计算指纹，保存分析结果，然后在每个文案/图片/Prompt优化/AI版式请求里显式附带产品资料与分析。
- V3.0.1 起全部产品实拍逐张发送；按 EXIF 校正方向并缩放到最长边不超过 1280px 的 JPEG，以减小单次请求负担，不修改原始文件。不是只发送图片路径。OCR/其他视觉检查仍保留原有分辨率。缺失或不可读的图片会报错。
- “分析 / 继续上下文”保留匹配资料的已完成分析，只续跑未完成图片；“强制重新分析全部”需确认，会重新请求并可能重复计费。资料、图片内容、模型或分析要求变化会使旧分析失效。关闭自动分析不影响主动点击分析按钮。
- 遇到 504、524 等临时错误时，JSON 接口按响应头 `Retry-After` 或 JSON `retry_after` 等待后重试（120 秒不会被截成 1/2 秒）。界面显示等待时间，原始错误响应仍保留。等待可暂停/继续；失败后的供应商等待期限也进入上下文恢复记录。要求等待超过一小时则停止自动重试，避免无限挂起。
- 网关超时来自供应商上游，本机延长 timeout 不能解除它的时限；轻量请求与续跑可降低反复失败成本，但不保证修复供应商故障。持续失败应换支持视觉的模型/供应商，或携请求时间与 Ray ID 联系供应商。
- 用户填写的规格和证据优先于 AI 对照片的猜测。AI被要求明确记录未知项、外观观察及冲突；分析结果仍需人工检查，尤其是材质、尺寸、容量、测试和认证。
- 分析失败不会假装成功继续生成。请查看具体响应，换支持视觉的模型或补齐资料后重试。
- V3.0.2 的生图请求只保留本品事实、变体、确认文案及本帧要求；不会携带整份竞品原文和全局关键词库。冗长逐图分析会去除重复事实并压缩观察条目，保留冲突和完整本品录入信息；完整分析仍在产品上下文页面和配置中。强制信息若超过32,000字符会在发送前报错，不截断用户提示词或确认文案。

## 为什么区分产品图与风格图

- 产品实拍决定外观、颜色、结构；风格参考仅用于布局、色调、摄影和文字层次。参考图里的竞品品牌、文案、功能不得自动变成本品事实。
- SudoCode、CUNAI 和其他 OpenAI 兼容入口选择 GPT 图片模型时，带图走 `/images/edits` 的 multipart 字段（单张 `image` / 多张 `image[]`），不再往 generations 发送 `image` 数据 URL，不发送不兼容的 `response_format=url`。16张以内且不配置跨协议后备时发送原图；超出数量上限、单图接口或跨协议后备时，内部缓存所有输入的用途标注拼图，不丢弃参考来源。该拼图不是 AI 生成草稿，不进最终图片包。原始照片不修改。
- 蒙版重生必须保持原图与蒙版几何对齐，所以实际生图输入保留原底图；产品理解、风格参考分析以文字提供，不用拼图替换被编辑图。结果仍需检查产品一致性。
- 第三方网关即使兼容聊天接口，也未必支持当前图片模型的参考图/编辑能力；请求参数正确不等于供应商一定执行这些参数。失败详情见日志，实际效果需要用你的供应商验证。

## 仅生成最终结果图

要求图片模型按已确认的德语原文、用户 Prompt 和卖点版式直接生成最终成图，白底首图不加文字。取消自动无字草稿、额外叠字副本、失败占位图片及预览素材切换；旧项目中的精确排字选项在运行时统一升级为最终成图。

模型仍可能漏字、拼写错误或不遵循布局，需 OCR 与人工审核。A+ 的 PC/移动端海报等比适配含字图，不自动重排文字；全部章节成功后才生成最终海报，不再补占位章节。修改确认文案后需重新生成图片才能改变画面中的字。

接口返回的图片数据解码保存为 JPG 后立即显示，早于 OCR、合规检查和整批 Excel 打包。第一张自动展开导出页顶部的预览，可取消“跟随最新完成图片”固定当前图片。此功能是逐张结果更新，不是单次请求过程中的低清草稿流。

逐帧图片 Prompt 高于自动建议；已确认原文、真实产品事实和白底首图约束优先。文案 AI 返回的旧 `image_prompt` 保留供历史参考，但不再成为覆盖用户逐帧输入的来源。模块确认页原有 Prompt 仍可使用；修改后会同步到该帧图片 Prompt。

## 版式与轮播边界

- AI版式是可编辑设计方案，不是 Amazon 官方模板或审美/销量保证。程序检查基本几何合法性、槽位完整性与文本框相互重叠；产品部位引线、真实图像遮挡、字体适配和最终视觉仍需人工检查。
- AI优化提示词不会直接改写已确认的六语文案；AI版式优化也不改写这些文案。需要改变文案时执行文案重生成。
- 导航轮播按帧生成独立文案、Prompt、图片和导出行；修改数量不会删除磁盘原始图。减少帧数会把多余帧移出当前任务。
- 1–20 是本程序的生成任务保护范围，不是 Amazon 后台允许的轮播数量。上传时还需按目标站点后台规格配置导航项、关联文本与模块资源。其他视频/多图/交互模块仍为设计参考，不会自动上传后台。

## 保存、日志与导出

- 两个逐帧 Prompt、参考图、产品理解、AI版式和轮播帧信息进入项目配置；每 2 秒自动保存及切换时提交。参考图通过原有图片托管机制保存副本，删除勾选仅移除引用。
- 请求/返回 JSON 展示保留 URL、模型、正文、HTTP 状态和响应等；密钥、授权头和 Base64 图片正文脱敏，避免泄密和界面卡顿。不要向他人分享未经审查的日志，日志中仍可能含商业产品资料。
- `project.json` 包含产品分析和逐帧配置；`briefs.json` 和 `partial_briefs.json` 包含实际请求 Prompt、上下文指纹和逐帧结果。
- Excel 保留设计、六语、PC/移动尺寸及“V3提示词与上下文”页。F列为上传的产品输入参考，G列为生成状态/错误，H列只放最终结果图；不再重复嵌入AI草稿。超过单元格长度的 Prompt 会分段写入。
- 最终 JPG 位于 `final_images/`，图片包为 `final_images.zip`（包括开启的最终 A+海报）。当前每帧只打包一个结果，不包含输入参考、旧历史版本或草稿；每个高级导航轮播帧独立输出。失败无新图，重生失败保留旧图并注明失败原因。已有旧输出目录不自动清理。
- 产品视觉理解、风格图解析、提示词优化及 AI版式都是额外 API 调用，会产生费用。现有费用预估不是账单，图片分辨率、输入图 token、重试及第三方定价会影响实际金额。

## 实现依据与验收方式

使用 OpenAI Docs 技能校验了官方[多图视觉输入格式](https://developers.openai.com/api/docs/guides/images-vision)和[图片编辑多参考输入](https://developers.openai.com/api/docs/guides/image-generation)。这不构成 CUNAI、SudoCode 等第三方供应商的兼容性认证。

本版通过本地模拟接口、真实 Tk 控件、配置往返及 Excel/JPG 导出测试验证；未使用你的真实 Key 发起付费生成。建议首轮只选择白底首图、一个详情模块和一个轮播组进行供应商实测。
